# 釣り・車中泊の温泉マップ

全国百名湯と、関西の釣り場の近くにある日帰り温泉を、1枚の地図で探せるページです。

**地図を開く → https://araaraai.github.io/japan-onsen-map/**

## 見られること

- **全国百名湯**: 松田忠徳『日本百名湯』の100湯。泉質・効能・代表的な日帰り施設の料金と営業時間・最寄りの道の駅とRVパーク
- **関西（釣り場の近く）**: 福井・三重を含む関西8府県の釣り場45エリアの近くにある日帰り温泉。料金・営業時間・近い釣り場
- **指数**: 釣り・車中泊向けの目安。車中泊スポット（と関西では釣り場）までの距離、料金、閉館時刻から点数にしています

## 注意

- 料金・営業時間は旅行サイト等の掲載値（2026年11月に確認）で、変わっていることがあります。行く前に施設へ確認してください
- 効能は、泉質を環境省の基準の「泉質別適応症（浴用）」に当てたものです。実際の掲示は源泉ごとに異なります
- 道の駅は宿泊目的の利用に遠慮が求められています（仮眠は可）。距離はすべて直線距離です
